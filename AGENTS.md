# Fluxo de atualização

A cópia de trabalho fica na pasta floripa bar plataforma da Área de Trabalho. Consulte o README para retomar a prévia e entender o estado atual.

Para alterações no código, execute npm test e npm run build. Use o Vite local na porta 5180 para a prévia. O envio ao GitHub será retomado quando o usuário indicar o novo repositório.
